## 배포 원칙

- Windows판 ZIP에는 x64/x86 실행파일을 함께 둡니다.
- Python판은 외부 pip 의존성 없이 표준 `tkinter`를 사용합니다.
- 원본 게임 D88, 원본 KANJI ROM, 패치 완료 전체 게임 이미지는 배포하지 않습니다.
- 실제 사용자 배포 ZIP은 GitHub Releases 자산으로 두고, 소스 트리에는 중복 보관하지 않는 것을 원칙으로 합니다.
