PatchyFM — Yuuwaku (Temptation) Kor v1.0

This Windows patching utility is adapted from the verified PatchFM Alltynex v1.0
workflow in KLostSoul/Patchy88. It verifies the user's original FM TOWNS
Yuuwaku IMG/BIN data track, automatically discovered under a selected folder
by content hash, and creates the Korean BIN/CUE via a provided xdelta3
patch, retaining no game image in the distribution.

Unlike the Alltynex PatchFM package, this package does not generate an ISO
using FreeTOWNSOS and does not ship FreeTOWNSOS components. The original
CCD/CUE/SUB companions are not patched or redistributed.

The patch was provided by the user for this packaging task. Original game,
translated game content, and rights to any game patch are not covered by
PatchyFM software's Apache-2.0 license.

xdelta3: jmacd/xdelta version 3.2.0. See UPSTREAM_XDELTA.txt and
THIRD_PARTY_LICENSE.txt for origin and licensing.

Verification: uploaded source + patch decoded to a byte-for-byte match with
the provided Korean BIN. Folder-mode tests passed, including recursive scan, wrong/duplicate source
handling, and existing-file protection. Windows GUI binaries cross-compiled for x86/x64;
Windows UI runtime and FM TOWNS gameplay were not tested here.
