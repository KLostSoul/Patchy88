PatchyFM Yuuwaku v1.02 — modification and distribution notice

PatchyFM v1.02 applies a user-provided Korean translation patch to the FM TOWNS
Yuuwaku MODE1/2352 CD data track. The previous v1.01 packaging was the base.

1) Replaced `Temptation-Korean-v1.01.xdelta` by the 330,776-byte user file
   originally supplied as `Temptation-Korean-v1.0(2).xdelta`, redistributed without
   modification to its bytes as `Temptation-Korean-v1.02.xdelta`.
2) Updated all manifest output hashes, generated BIN/CUE names, user documentation
   and the two Windows GUI executables to v1.02.
3) Strengthened patcher memory and delivery safety: bounded xdelta diagnostic
   capture (64KiB per stream); 5-minute external process timeout; complete
   content hash checks even when Go reports a late-closing output pipe; verified
   target publication and cleanup of incomplete temporary output files.
4) The supplied patch changes TMB.COM compared with v1.01 (stack-memory error
   fix reported by patch author). No claim of independent FM TOWNS runtime testing.
5) No original game files, complete CD image, translated full BIN, User Disk,
   or FreeTOWNSOS are included with the distribution.
