PatchyFM — Yuuwaku (Temptation) Kor v1.01

This FM TOWNS Windows patcher is based on the Patchy88 project's
original validation approach. It recursively scans a user-selected folder
for a verified Yuuwaku IMG/BIN CD data track, then applies the revised
xdelta patch and produces Korean BIN/CUE output. The original game
tracks and final game images are not redistributed.

The supplied revised patch was uploaded as Temptation-Korean-v1.0(1).xdelta.
For this v1.01 packaging, its raw bytes were preserved and the bundled
copy was named Temptation-Korean-v1.01.xdelta.

The resulting BIN was reconstructed from the provided original IMG with
a separate RFC 3284/VCDIFF decoder; its window-level Adler-32 checksum
was verified. That decoder was cross-checked against the old v1.0 patch
and the previously supplied v1.0 Korean BIN. Windows amd64/386 builds,
Go unit tests, and nine Linux integration checks with a validated
VCDIFF decoder substitute passed. These checks do NOT establish that
the Windows GUI or bundled Windows xdelta3.exe ran on a Windows machine,
and game boot in Tsugaru has not been verified here.
